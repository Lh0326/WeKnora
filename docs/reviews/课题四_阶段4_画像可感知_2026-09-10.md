## 1. 实际行为变化与理由

**新组件（3 个 Vue 组件 + 1 个 API 模块）**：

| 文件 | 内容 |
|---|---|
| `frontend/src/api/learning/objectives.ts` | 目标层 API：getObjectiveProgress / getObjectiveView / postShortPath；类型与后端字段名一致（不从 p_eff 推断） |
| `frontend/src/views/knowledge/learning/ObjectiveProgress.vue` | 分离进度条：**"已验证 X/Y 个学习目标"** 为主数字（非概率），冲突/过期/部分/未测并列各自计数；**接触覆盖另列一行**，明确"接触不等于已验证"；自述计数单独显示 |
| `frontend/src/views/knowledge/learning/PathPanel.vue` | 学习路径面板：当前步骤突出（➤），后继步骤灰显+标前置条件（`Requires` 字段显示，不冒充已解锁）；每步显示**动作徽标（六词表）+ 标题 + 预计分钟 + 原因短语 + 完成条件**；降级路径有文字说明不空白 |
| LearningTab.vue 集成 | 两个新组件插入在覆盖建议卡上方（紧接星图区域）；数据在 refresh() 中并行拉取（Promise.all 追加 2 个 catch 容错）；fetchPath 在 onMounted 调用 |

**后端（1 个新端点 + 类型）**：

| 文件 | 内容 |
|---|---|
| `objective_progress.go` | ObjectiveProgress 服务方法：从 ObjectiveView 五维度推导分离计数——已验证/冲突/过期/部分/未测目标数 + 接触节点数 + 自述计数 + legacy 试次数；**绝不从 p_eff 折叠推断** |
| `interfaces/learning.go` | ObjectiveProgressSummary 类型 + ObjectiveProgress 服务接口 |
| `handler + route` | GET `/api/v1/learning/kb/:kb_id/objective-progress` |

**四语言文案（29 键 × 4 语言 = 116 条）**：全部用"学习目标/已验证/接触/证据"词汇；无一处出现"掌握概率"；接触覆盖显式标注"接触不等于已验证"。
