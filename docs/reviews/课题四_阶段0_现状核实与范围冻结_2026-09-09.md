## 链路核实结果（真实行为，非注释）

### L1 事件采集、过滤与折叠——哪些弱信号进 logit

- 全部写入走 `runSubject → repo.WithSubject`（主体锁事务 + 代际捕获）：`transaction.go:13-80`；窗口读取用全量分页 `event_window.go:14-38`（防 agent 留痕挤掉人类去重证据）。
- **当前所有弱信号都折入同一 logit**（`constants.go` 权重表 + `collect.go:weightForType`）：
  - 进 logit 的正信号：answer_cite +1.0、cross_ref +1.6、topic_signal +0.5、**wiki_tool_read（人类阅读）首触 48h 内 +0.5**（`service.go:recordWikiRead`——窗口内重读零权重但仍记时间线）、wiki_deep_read +0.3、backfill_cite +0.5×饱和、quiz_correct +2.2；
  - 负信号：quiz_wrong −1.5、re_ask −0.8（`fold.go:26-51` 负更新先吸收衰减，负地板不奖励失败）；
  - **零权重不折叠**（`fold.go:15`）：agent_read（通道已分离）、去重重读、quiz_unsure、看过反馈后的 48h 内重答。
- 稳定性 = 计数纯函数（`fold.go:93-101`，FSRS 启发）；等级 = p_eff 阈值 + 滞回（`constants.go` 0.30/0.55/0.80）。
- **结论**：与 01 方案 §5.2"弱信号只改推荐入口、不进能力分"相比，现状是**混合分设计**——阅读/引用/话题与答题共用一个 logit；仅靠 direct gate 在展示层封顶（见 L2）。

### L2 direct evidence gate——重复/重试/跨天/新失败

`gate.go` 全文核实：

- **重复**：`CollectDirectFacts`（gate.go:86-125）按 **QuizItemID** 去重——同 item 再答对不产生第二个 fact；刷单题无法伪造广度。
- **答错后重试**：`IndependentQuizAttempts`（gate.go:53-82）按 (tenant,kb,subject,slug,item) 在**上一次任何作答后 48h 内**的重试整条剔除（含先错后对的"看解析纠正"）；同刻时间戳时失败/不确定排在正确重试前（不遮蔽）。
- **跨天重复**：>48h 的重答恢复独立资格； mastered 门槛读 first→last 跨度 ≥48h（gate.go:147-160），"首日全对+隔天全对"可解锁（P1-C 死角已修）。
- **新失败**：quiz_wrong −1.5 折入 logit、稳定性收缩；后续独立失败不自动撤销历史 verified（无 conflicting 状态）。
- **封顶规则**（gate.go:139-179）：0 对→touched 封顶；≥1 个不同 item→familiar；≥2 个不同 item 且跨度≥48h→mastered。封顶只降不升；衰减仍可继续降档。
- **缺口**（对照 01 §5.3/6.1）："不同 item_id"≠"不同题族"——无 family 概念；无 unverified/partial/verified/conflicting/stale_content 目标状态机（只有节点级四档+gate 封顶）；无验证契约版本化。

### L3 题目生成→审核发布→答案暴露→来源更新→判分

- **生成**：`maintenance.go:runQuizPass`——LLM 出题 → `quizgen.go:validateQuizDraft` 结构校验（四选项/正确键/ChunkRefs⊆页面引用/去重）→ 写入即 **active**，带 `quiz-evidence-v2` 证据哈希（`quizgen.go:97-99`：页面标题+类型+slug+正文+截断证据集）。
- **审核/发布：不存在**。`routes_learning.go:34-35` 仅有 quiz 取题/作答两条路由；无题目管理/停用/发布接口；`LearningQuizStatusDisabled` 类型存在但无写入方。**生成即上线，唯一闸门是结构校验与证据哈希**。
- **答案暴露**：每次提交即返正确键+解析（`read.go:submitAnswerNode`）；`grade.go:55-57` 据此把 48h 内重答权重归零（练习不冒充独立证据）。
- **来源更新**：服务/判分双端实时校验证据哈希（`quiz_evidence.go:60-66`；`read.go:681-683` 计分后复核、失配回滚个人事务；`TakeQuiz` 只下发 active+哈希匹配项且未见题优先）——材料漂移立即停发停判。维护遍历页/题并集处理删页/空引用/缺失材料（验收报告 R3，测试 `quiz_stale_regression_test.go`）。
- **判分**：`grade.go:GradeQuiz` 纯确定性（零 LLM）；非法选项拒绝；"不确定"=零权重申报。**判分确定性≠题目有效**——无人工审题环节（01 §6.1 的隐性黑箱警告适用）。

### L7 learning-bench 各模式

（代理逐文件核实，要点）simulate=合成断言集（曲线形状/滞回/四人格门控/迁移无损）；replay=下一次行为预测（HitRate/MRR，static+online 双协议、micro/macro），泄漏纪律严格（等时批先预测后观察、宇宙生长、人类事件过滤、快照严格过去含 created_at、original_slug 回滚，均有测试钉死），无快照时明示"observed-node proxy"降级；optimize=时序校准（quiz 前 p_eff 预测作答结果，log-loss+收缩，70/30 轨迹内切分，护栏=次序约束+±50% 邻域+gateSafety 人格回归），明示"非未见用户/非学习效果评估"；verify=28 项分层规则一致性；walk=15 步活体 API 链路契约。
