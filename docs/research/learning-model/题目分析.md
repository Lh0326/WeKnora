# 课题四：算法主导、反馈校准的学习模型

日期：2026-09-11。状态：模型、路径和界面已接入，正在完成回归与真实页面验收；结果以同目录《验证记录》为准。

## 1. 目标和原始要求

依据用户本轮目标、初版 `weknora-4q.md` / `weknora-ans.md`，以及本机《WeKnora 开源实战课题.docx》的课题四正文：

- 关联：个人记忆、实际引用与知识内容建立可解释映射。
- 度量：定义知识点掌握状态和观测信号，避免大模型主观评分。
- 引导：依据估计状态推荐看什么、练什么，行为回流后自动更新。
- 呈现：用户可以理解节点为什么亮、为什么推荐以及如何纠正。
- 原型交付：设计说明、可运行原型、一种有效性验证；保留个人画像隔离、查看、导出、删除。

用户反馈应是观测与纠偏，不能成为每个节点继续学习前必须完成的状态录入。无题库、无反馈的冷启动也应能自动形成有解释的初步估计与学习顺序。没有标签时，估计的确定性不能随点击次数虚增。

## 2. 现有两条路线的不足

初版 `sigmoid(累计权重) × 遗忘因子` 的问题不只在数据量。答案引用、话题兴趣、真正理解并不等价；短时间再问一次也可能是在深入追问。把这些信号直接解释成掌握概率，换一个更大的数据集并不能消除标签错配。零 logit 的 sigmoid 为 0.5，亦不适合作为未经校准的新知识点起始掌握概率。

改造前的主页面采用“自认已会 / 待巩固 / 验证通过”规则，保留了事实边界，却把度量主线交给了用户。短路径中“阅读后要求确认”的行为，正是这种重心变化的直接结果。

新方案保留事件与证据分离的基础，把连续估计和基于估计的规划重新接回主页面。已验证通过仍是独立事实，不用估计分数替代，也不要求所有学习先进入完整审核流程。

## 4. 最小模型结构

每个用户、知识库、知识节点、内容版本维护可重放的状态：

`X = (阅读覆盖 C, 理解估计 M, 估计敏感性 U, 回忆状态 S/D/R, 来源与证据 E)`。

这些量含义不同，不强行压成一个“精确掌握百分比”。主视图使用算法估计的熟悉等级及其依据，用户声明和已验证事实显示为辅助标记。

### 4.1 关联和信号分类

- 实际答案引用与页面来源求交集，形成接触证据；话题映射主要影响工作相关性。
- 页面可见且有效停留形成学习机会。按内容长度估计阅读成本，短页和长页不共享固定“读完”秒数。停留只能估计覆盖，不能证明理解。
- 同一页面、同一学习会话的浏览与深读合并，刷新页面、重复提交和后台停留不能无限累积。
- 答题以第一次未见答案的结果为主要观测；同题答案揭示后的立即重试不再当独立掌握证据。
- “已经会了 / 仍然困难”是有噪声的主观观测。用户可临时跳过或调整范围，算法遵守这些行动意图，但不把它们伪造成客观正确标签。
- 回忆成功或失败才进入 FSRS。引用、打开页面、点“已会”不会被自动转换成 FSRS 的 Good。

### 4.2 理解估计：受约束 BKT 与弱学习机会

基本 BKT 参数为初始掌握率 `L0`、学习转移率 `T`、猜对率 `G`、失误率 `S`。记当前潜在理解估计为 `m`。

下次作答的预测正确率：

`q = m(1-S) + (1-m)G`。

观测正确时：`m_obs = m(1-S)/q`。

观测错误时：`m_obs = mS/[mS+(1-m)(1-G)]`。

读过解释后才考虑学习机会：`m_next = m_obs + (1-m_obs)T`。报告中分别记录观测后的状态与学习转移后的预测；不能把后者误称为已经答对的证据。

参数需满足非退化边界及 `G < 1-S`。初版实测不足以拟合每个人的全部参数，因此先比较公共参数、仅总体拟合、少量数据收缩校准三种策略。个人数据不足时退回先验，不拟合大型行为模型。

**被动阅读扩展属于本项目假设，不是标准 BKT 已验证能力。** 无正确标签的阅读只做预测转移，不做“答对”贝叶斯更新：

`T_read = 1 - (1-T)^(ρ·c)`，`m_next = m + (1-m)T_read`。

其中 `c∈[0,1]` 是有效覆盖剂量，`ρ` 为阅读机会相对练习机会的折扣。先对 `ρ∈{0.1,0.25,0.5}` 做敏感性比较；选择的值必须标明为原型假设，后续用本地独立作答调整。重复弱事件采用每日/会话去重和边际衰减，弱信号单独不能累积成高确定性的“已掌握”。

无标签时对多组合理先验同时递推，呈现估计范围及“依据较少”。这只是参数敏感性范围，不冒称统计置信区间。一次阅读即可产生可见的覆盖和初步熟悉变化，并自动继续安排学习，不要求用户逐页确认。

### 4.3 反馈如何成为校准而非主导

显式自评采用有上限的似然修正，独立于客观验证；重复点击相同评价不重复加分。评价的默认可信度是待检验假设，不能宣称来自 Anki 或公开作答数据。

一旦出现后续独立作答，将预测与实际结果配对。公开子集比较了单个 logistic 偏移的收缩校准，3 条标签出现退步，10 条标签仅有小幅改善，尚不足以支持在企业阅读场景默认启用参数拟合。因此当前在线采用状态后验校正，个人参数拟合保留在离线实验中。只有新场景训练段和验证段支持改进时才启用个性化参数；不凭个人十几次点击重拟合全部参数。

已有 `assessment-freeze` 接口现在同时返回节点模型估计、内容哈希、模型版本和冻结时间。后续独立检查应先保存此快照，再记录结果；不能事后用新模型倒推旧预测充当前瞻数据。日常估计中的 `last_answer_prediction` 是固定版本的顺序重放值，用于调试因果顺序，不能替代已保存的前瞻快照。

需纠正的不是“用户没有操作”，而是“预测与后续表现不一致”。低确定性、高价值或模型与反馈冲突的节点可偶尔推荐一次简短检验；检验不是正常阅读路径的必经步骤。

### 4.4 记忆保持：FSRS-6

使用上游默认参数和正式回忆事件重放得到稳定性、难度、保持率与复习时间。用户反馈“忘记 / 费力 / 正常 / 轻松”分别映射 Again / Hard / Good / Easy，其中后三者都代表确实回忆成功。

原有 SM-2 记录保留事件与规则版本，迁移应从真实历史重放；没有回忆历史的节点不制造初始成功记录。首次阅读只能安排建议检查点，不能据此伪造 FSRS 已校准的保持率。

**BKT 的技能正确率与 FSRS 的材料回忆率不相乘、不取平均。** 它们预测的对象不同：前者用于理解/练习选择，后者用于有回忆历史的复习时机。界面给出相应解释，避免重复计算同一证据。

### 4.5 引导：收益、信息和时间成本

在用户选定范围、时间预算和必要先修约束内，比较候选动作：阅读、补前置、轻量练习、到期回忆。

- 阅读的预期状态增益由 BKT 转移给出 `(1-m)T_read`，不用人为“已会”名单主导排序。
- 有回忆历史的复习需求由 FSRS 预测与目标保持率的差距给出。
- 检验价值由预期减少的不确定性衡量，限量安排，防止把学习页变成连续考试。
- 结合任务相关性、可解锁后继节点和阅读成本，在预算内选择并排序；先修边区分建议关系与已确认约束。
- 提供可重放的探索名额，避免只推荐已熟悉或高频主题。探索与检验均受时间成本约束。

组合排序是本项目的决策模型，不冒称已有论文证明其对企业知识库最优。各项贡献应可输出解释，并做移除个性化、移除掌握估计、移除反馈校准的消融比较。

最小组合：公开作答子集验证递推与小样本策略 + FSRS 默认参数和上游契约验证 + 少量本地前瞻记录。公共数据提供模型起点，本地数据用于修正场景差异。

模拟行为只检查冷启动、去重、遗忘、反馈冲突、预算和先修约束。不能以“用模型生成数据，再由同模型预测成功”证明模型有效。

## 6. 评估协议与交付门槛

1. **知识追踪预测**：按用户隔离训练/验证/测试，再在测试用户内部按时间进行先预测后观察。比较固定先验、训练段常数/技能均值、BKT、少样本收缩校准。指标至少包括 log loss、Brier、分箱校准误差及样本/用户数。不以 AUC 单独判断概率质量。
2. **少样本实验**：冻结同一后续测试段，只让校准器看到前 0/3/5/10 条结果，比较偏移校准与不校准。当前小子集多数用户不足以支持原拟 20/50 条前缀，调整依据和时间见《验证记录》。数据量扩大不等于效果必然提升，失败结果照常记录。
3. **记忆实验**：上游参考向量、同日记录、跨日遗忘、失败、内容变更和历史重放验证；取得合规的真实复习数据后再报告预测误差。在公共默认参数可能已使用该公共数据训练时，不宣称严格独立的外部验证。
4. **推荐实验**：在预先定义的知识切片、目标与预算上，比较目录顺序、现有用户状态规则与模型方案。检查目标覆盖、前置缺口、重复阅读和成本。公开作答预测成绩不能替代本项。
5. **真实页面**：不点击“已会”也能看到自动估计变化和推荐推进；一次反馈会修正估计与推荐；刷新后结果可重放；星图、右栏和助手使用同一估计；没有题库仍可学习。
6. **基本工程**：沿用现有身份隔离、停采、导出、删除与版本语义；相同输入、相同模型版本、相同时间得到相同结果。

整体完成需要上述实现与相应证据。撰写本方案、单独跑通 BKT 或仅替换复习公式均不能据此宣布课题四改造完成。

## 7. 实施顺序和当前证据

先完成公开子集基线与小样本实验，决定哪些校准规则值得采用；随后实现可重放估计器、FSRS 接入、基于估计的规划和轻量展示，最后完成真实页面验收。每阶段将结果和失败情况写入同目录验证记录。

已完成原型实现与验收：公共数据先导实验可复现，BKT/FSRS 核心接入节点、路径、星图、右栏和助手；真实页面观察到无声明的阅读推进、反馈纠偏、回忆安排保存及刷新恢复。参数敏感性与决策消融结果、最终工程回归见 [验证记录](验证记录.md) 的收尾章节；下一阶段如何获得本地校准数据见 [数据集使用方案](数据集使用方案.md)。阅读转移参数、自评可信度和真实学习效率收益仍未经过企业场景数据验证，不能由工程验收替代。

## 8. 当前原型的精确策略（对应源码版本）

理解模型为 `bkt-reading-envelope-v2`，路径为 `path-plan-v7-model`。不新增数据库或后台训练服务。

| 项目 | 当前实现与解释 |
|---|---|
| 冷启动 | `L0 ∈ {0.15,0.25,0.4}` 与 `T ∈ {0.15,0.3,0.45}` 组成九组等权假设；`G=0.25,S=0.15`。这些是待检验的企业阅读原型假设，未使用数学练习的拟合参数冒充本地校准 |
| 阅读机会 | 可见停留 5 秒产生初步机会；持续阅读阈值按非空白字符 / 350 字每分钟估算，限制为 8–180 秒。两种阅读入口共用该规则。时间与字符数仅为成本启发式，不代表读完或理解 |
| 去重与衰减 | 单节点、UTC 自然日累计剂量最多 1；普通阶段为 0.25、持续阶段总量为 1，只在原时间戳补记增量。边际剂量 `d = log(1+ΔC/(1+C累计))/log(2)`，阅读相对效力 `ρ=0.25`。拆成普通/持续两次不会多算一次学习机会，也不会抹去两次阅读之间的答题预测 |
| 答题更新 | 合格的独立作答做贝叶斯观测更新；未观测到阅读解释时，不自动追加“已学习解析”的状态转移。错误因此不会仅因展示了解析而提高理解估计 |
| 主观纠偏 | 已经熟悉的似然比为 8，仍有困难为 1/8；重复同向声明不累加，正反因子互为倒数。它们不制造客观答题或 FSRS 回忆记录。独立作答可推翻声明；补看内容可解除待巩固的行动提示 |
| 熟悉等级 | 先验节点仍显示未接触；有接触为初步接触；完整阅读机会或独立作答为阅读推进；均值 ≥0.65 且存在独立作答、纠偏或累计三次机会时为估计熟悉。最近困难/失败尚未回看，或已加入的回忆到期，则建议巩固。验证通过另行显示 |
| 阅读排序 | 预计下一阅读增益 / 分钟，乘有上限的工作相关性与后继节点解锁权重；刚持续阅读的节点在 30 分钟内收益再乘 0.2，避免立刻重复。显式范围、排除与已审核先修约束优先 |
| 少量自测 | 没有显式验证目标时，最多一个已具备题目的检查，成本不超过预算 1/4；阅读后、预计信息增益 ≥0.15 bit、近 24 小时未独立作答且先修满足才可推荐。已有到期回忆或待巩固行动时不再叠加自动自测 |
