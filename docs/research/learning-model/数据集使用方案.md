# 课题四：不依赖大量个人数据的建模与校准

当前采用“公开数据检验方法、默认参数启动、本地少量独立结果检验迁移”的组合。用户不必先积累大量点击，也不必逐页确认。公开数学作答、材料回忆、企业文档理解属于不同任务，不混成同一种掌握标签。

## 已能使用的数据

| 数据层 | 本项目实际用途 | 当前结果与边界 |
|---|---|---|
| pyBKT 作者的 Cognitive Tutor 示例 | 用户隔离的知识追踪实验；检验少量个人标签能否改善预测 | 已运行 16,857 条记录、587 位用户、12 项技能。拟合 BKT 没有胜过技能均值基线；3 条标签的校准反而变差，10 条仅小幅改善。因此未把拟合参数直接搬到企业阅读 |
| FSRS 上游默认参数与算法 | 无个人历史时提供复习模型起点，随后按真实回忆结果递推 | 正式 go-fsrs v4.0.0 / FSRS-6 已接入。无需先下载巨量复习轨迹；本项目没有自行重训其参数，也不声称重新验证了大规模预测精度 |
| 本地知识节点与独立作答 | 检验阅读折扣、自评可信度及推荐的场景适配 | 已有模型快照接口和外部挑战流程。真实企业学习效果实验尚未执行；代理的页面验收不能作为真人样本 |

更大规模的候选为 [Anki Revlogs 10K](https://huggingface.co/datasets/open-spaced-repetition/anki-revlogs-10k) 和 [Duolingo HLR](https://github.com/duolingo/halflife-regression)。前者有访问条款，本轮未代用户接受。它们适合后续回忆预测研究，不是企业知识理解的现成真值。完整来源、版本、许可边界见 [模型分析](题目分析.md) 第 3、5 节。

## 复现已经做过的公开实验

在项目根目录，使用安装了 NumPy 的 Python：

```powershell
python scripts/learning_model_benchmark.py --fetch --out .local-data/research/learning-model/public-bkt-reproduced.json
python -m unittest discover -s scripts -p test_learning_model_benchmark.py -v
```

程序只在本地不存在文件时下载作者固定提交中的约 4.4 MB 示例；原始学生轨迹放在忽略目录，不提交到仓库。发布的 [public-bkt-results.json](public-bkt-results.json) 保存源提交、文件哈希、样本分割、参数、指标和限制。

训练、验证、测试按用户分开；每一步先预测再读取答案。个人校准只看前 0/3/5/10 条，比较的是同一段后续记录。此次测试集已经用于先导分析，后续调参不能把重复使用它称为新的盲测。

## 最小本地数据方案

可先选 10–20 个有清晰学习目标的知识节点，准备少量未进入日常题库的独立检查。这个规模用于发现明显误判，不是统计功效保证，也不是要求用户先完成一套考试。普通阅读照常运行，只在事先选定的检查点取样。

每次检查保留以下对应关系：

| 记录 | 用途 |
|---|---|
| 匿名参与者、知识库、节点 slug、正文哈希 | 防止把不同人、不同材料混在一起 |
| 模型版本、冻结时间、理解指数及敏感性范围 | 明确回答发生前算法究竟预测了什么 |
| 阅读机会、是否做过自评及其时间 | 比较有无纠偏时的预测，不能把自评本身当正确答案 |
| 独立题族、展示时间、作答条件、第一次结果 | 保证当前标签未进入当前预测；看过答案或用过助手应另行标记 |
| 未作答／退出及原因 | 保留完整分母，不把没有回答的人默默删掉 |

现有 `GET /api/v1/learning/kb/:kb_id/assessment-freeze` 返回 `learning_model_version` 与 `node_estimates`，在同一用户事务内冻结。既有 `scripts/learning_assessment.py capture` 会原样保存整个 `frozen` 对象；后续 `present` 与 `grade` 保留其来源链。实际操作方法见 [独立评估执行说明](../../evaluation/objective-learning/README.md)。这是可选的数据收集工具，不是学习页的日常必经流程。

对于同一四选一、闭卷题型，可在模型版本固定为当前参数时使用 `q = 0.25 + 0.60 × M` 检查下一次正确率预测。潜在理解指数 M 不能直接当作答对概率；结构化多字段任务与回忆难度也不能混入该指标。旧 `last_answer_prediction` 是重放值，不能替代答题前保存的快照。

建议先报告预测误差与误判实例，再决定是否拟合参数。默认保留简单技能／内容均值基线，按参与者或未来时间段保留新的验证数据。只有校准在未参与调参的本地数据上稳定改善时，才启用参数个性化。一个人的多次点击不是多位独立用户；个人自测可以检查自己的流程，不能证明面向所有员工的收益。

## 用户反馈的职责

当前反馈修改节点状态后验，不重新拟合全部模型参数。“已经熟悉”与“仍有困难”的影响有上限、同向重复去重，不增加客观验证记录。后续独立作答可以修正自评；继续阅读可以自动更新后续顺序。是否采用当前默认反馈权重，应由上述本地记录检验，而不是通过增大权重让用户更容易点亮来证明合理性。

本轮真实页面中由代理产生的阅读、纠偏、回忆及助手问答全部属于工程验收数据。验收复习已暂停，历史保留；未来评估应使用未受这些操作影响的节点／试次或独立测试账号，并显式排除该批记录。
