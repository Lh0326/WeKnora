# 课题四模型术语

| 中文 | 英文/符号 | 定义 |
|---|---|---|
| 知识节点 | knowledge component / node | 当前版本的实体或概念页面；过大页面后续可按目标细分 |
| 阅读覆盖 | reading coverage / C | 根据可见阅读机会估计的覆盖剂量；引用仅表示接触，不增加此剂量；两者均不是真实理解标签 |
| 学习机会 | learning opportunity | 用户接触材料或解释后可能产生理解变化的一次机会 |
| 理解估计 | latent proficiency / M | BKT 等状态模型给出的潜在理解程度估计 |
| 预测正确率 | predicted correctness / q | 在指定题型及参数下，下次作答正确的预测 |
| 先验 | prior / L0 | 没有个人观测时的起点；公共场景参数存在迁移不确定性 |
| 学习率 | learning transition / T | 一次学习机会后由未理解转为理解的模型概率 |
| 猜对与失误 | guess / G; slip / S | 知识状态与实际答案之间的观测噪声 |
| 敏感性范围 | sensitivity envelope / U | 不同合理参数假设下的估计范围；不冒称统计置信区间 |
| 自评纠偏 | self-report correction | 有限权重、有噪声的用户反馈，不覆盖客观事实 |
| 记忆稳定性 | memory stability | FSRS 中决定遗忘速度的状态量 |
| 记忆难度 | memory difficulty | FSRS 根据回忆历史更新的难度状态，不是页面字数 |
| 保持率 | retrievability / R | 对相同回忆材料在某时刻回忆成功的预测概率 |
| 收缩校准 | shrinkage calibration | 小样本个体参数向公共先验收缩，抑制过拟合 |
| 预期信息增益 | expected information gain | 一个检验结果对减少状态不确定性的预期价值 |
| 已验证事实 | verified evidence | 符合既有验证契约的作答记录；不等同算法预测 |
| 前瞻评估 | prequential evaluation | 先保存预测，再观察结果并更新；当前标签不能参与当前预测 |
