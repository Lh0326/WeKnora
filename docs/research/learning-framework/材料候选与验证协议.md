# 材料候选：运行前固定的协议

2026-09-12。目的：让带条件的学习单元能够从不同主题材料产生，而不依赖课题四报告中手写的十个键；不把自动生成等同内容正确。

## 本轮边界

- 输入为明确选择的同租户、同库 1–6 个完整 Wiki 页面，每页最多 8,000 字符、合计最多 24,000 字符。超限、空白、归档来源拒绝整次请求；不截断段落后假装保留完整上下文。Wiki 已丢失的原文章节不能由本流程恢复。
- 复用知识库已有生成模型，一次请求最多 8 个候选，温度 0；只在输出截断时重试一次，总超时 120 秒。输入仅共享材料，不读取个人记忆、学习事件或模型画像。
- 候选按“目标 + 适用条件”划分，跨源同义可以建议合并、同名异用应分开；这是模型任务，尚不保证语义识别准确。保留逐字引文和来源版本。
- 不强制生成测验。导入后的单元允许 0–3 道检查；没有题目仍可阅读、表达困难、减少重复阅读和安排真实回忆，无答题观察就不展示能力数值。
- 生成结果只返回草稿，不写共享组件、个人状态或硬先修。模型给出的先后关系最多保留为相关候选。内容复核后另行导入；复核说明不冒充独立人工评审。
- 结构校验包含目标边界重复、真实引文、来源范围/版本、完整解释与例子；不使用模型自信分数、字数或引文存在来证明语义正确。

## 运行前固定的验证

1. 生产导入与状态链：无题材料可导入，阅读后不反复推荐阅读、不安排不存在的检查、表现观察仍为零；主动回忆不要求先有测验。
2. 生成链：同页多目标、同名异用、跨源同一目标；输出格式错误、引文不存在、来源变化、超限、跨用户/租户资料、未经复核的草稿导入、假硬先修与自动题目均须处理。模拟模型的测试只证明机械边界。
3. 实际模型：明确记录模型与输入版本，保留首次输出及所有拒绝；先检查引用，再逐项核对目标、条件、解释、例子、不同来源的冲突。作者核对不称为独立语义评估。
4. 跨主题固定样本使用软件并发、数据统计、工作流程三类自编完整短材料；同名词不同语境、同义不同来源、条件冲突、信息不足各有对应案例。样本是可审计的合成边界集，不代表真实企业语料分布；完整保留失败，不据此宣称已测得学习提升。

本轮不训练新模型、不增数据库表、不搭建课程审核平台。实际学习效率仍需学习者对照；代码验证与来源审查不得替代该结论。
