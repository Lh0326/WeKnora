# 术语与变量

| 术语/符号 | 在本项目中的含义 | 不应混同 |
|---|---|---|
| 组件 k | 在明确条件下可学习、可观察的目标 | 固定字数块、名词实体、整页能力 |
| 版本 v | 定义和来源的冻结版本 | 当前页名 |
| 覆盖 C | 接触、有效阅读机会 | 已掌握 |
| 表现证据 E | 首次独立题族的检查事实 | 求助练习、自评 |
| 意图 I | 用户目标、熟悉/困难声明 | 已验证能力 |
| 保持 R | 真实回忆反馈形成的记忆状态 | 通用理解或页面停留 |
| 需求相关性 | 记忆/常用资料与目标的候选联系 | 掌握证据、先修关系 |
| 先修 | 完成当前目标前有依据的准备条件 | 语义相似或 Wiki 链接 |
| BKT | 由隐状态和观测假设定义的知识追踪候选 | 客观可测的掌握真值 |
| 历史回归 | 用过去成功/失败计数预测响应 | 用当前答案作为特征 |
| 校准 | 预测概率与对应结果频率的一致程度 | AUC 排序能力 |
| 敏感性范围 | 改变模型假设后的输出变化 | 统计置信区间 |
| 用户层 bootstrap | 按用户重抽样比较模型损失差 | 把同一用户多条记录当独立样本 |
| 规划效用 U | 给定目标、约束和权重下的排序标准 | 未经验证的真实学习收益 |
| 泛化 | 明确分布边界下对新对象的可迁移能力 | 在数学数据集上成功便适用所有文档 |
| 有效性 | 与明确基线相比，在预定指标上的证据 | 能运行、界面美观或测试数量 |
