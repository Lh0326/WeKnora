# 课题四：个人学习原型设计与验收

2026-09-12。本文汇总四个切入点的最终原型方案，替代早期文档中“阅读累加即可提高掌握指数”的实现说明。历史实验、冻结协议和失败结果保持原样。交付范围是课题要求的可运行算法原型；不把离线结果表述为真实学习收益或上市质量认证。

## 1. 要解决的问题与选型

原题要求打通个人长期记忆与知识内容，让学习者看到接触、盲区以及下一行动。用户进一步要求四个角度都优化，保留白绿知识星图，避免把 Wiki 片段拼接阅读或企业知识健康治理变成课题主体。

主单位选择**学习目标及其适用条件**，简称学习单元：稳定身份、目标、适用条件、完整解释、例子、多来源引文、材料版本，以及经过整理的前置或普通相关关系。来源是学习材料的依据；个人状态属于这个目标的当前版本。一个词在不同条件下的用法可以分开，同一规则可以引用多个来源。这个结构不自动找回 Wiki 已经遗失的上下文。

不采用“越细越好”的切分规则。模型只能生成候选，不能自批发布、给自己生成的题打有效性标签，或把推测关系变成硬先修。导入前核对来源与条件；无题目标同样可以学习。通用入口复用现有模型、Wiki 仓储和事件表，整个组件方案增加一张共享材料表，复习复用 go-fsrs；无需另建训练服务或课程运营系统。

## 2. 四个角度的算法与数据边界

| 角度 | 当前算法骨架 | 数据与不变量 |
|---|---|---|
| 关联 | 个人主题通过 Wiki 映射、常用文档通过出处关联到学习单元；同一记忆来源命中 n 个单元时按 1/n 分摊，合并重复路径，单元相关权重封顶 | 使用有时效和权限的个人输入；保留解释。相关性只影响推荐，不能提高掌握或替代前置。无有效信号时正常回退 |
| 度量 | 分离阅读覆盖、自评意图、独立检查、真实回忆；检查使用简单贝叶斯观测更新，回忆使用 FSRS-6 | 阅读和自评不更新表现指数；同版本同题族只计首次合格检查。未观察表现时隐藏能力数值；旧材料结果不能升级新材料 |
| 引导 | 目标及必要前置共同进入时间预算；保留可行贪心下限，小集合搜索可达子集，大集合采用有界搜索；可选检查占独立预算 | 阅读、困难、到期回忆和个人相关性是公开偏好权重。效用不是学习收益；截断或未覆盖目标会明确说明 |
| 呈现 | 星图、六类状态、导航、阅读详情和助手共用当前状态；保留点击、缩放、复位和可解释下一步 | 接触能点亮，读过能继续，自认熟悉能减少重复推荐；检查支持单列。不要求所有内容先答题才能继续 |

组件模型 `kc-evidence-separated-v2` 的独立检查更新为：

- 答对：`p' = p(1-s) / [p(1-s) + (1-p)g]`。
- 答错：`p' = ps / [ps + (1-p)(1-g)]`。
- 原型使用初值 0.1、0.2、0.35，猜测参数 g=0.25、失误参数 s=0.1。阅读不施加学习转移，自评不施加似然比。
- 中间初值对应的指数及不同初值结果仅在有独立检查时作为实验详情显示。参数未在本地学习者上校准，范围不是统计置信区间。“检查支持”也仅代表当前原型检查记录，不能替代现实工作能力认证。

这里的“自动化”是自动采集有效阅读、重放个人状态、重算推荐和复习安排；不把自动猜测用户已经学会作为自动化目标。熟悉、困难和回忆反馈是可选输入。

## 3. 未配置学习单元的知识库

这些库仍以 Wiki 页面提供可用入口，**不会冒称已经完成新粒度材料整理**。本次将其统一为 `page-evidence-separated-v3` 与 `path-plan-v8-evidence`：

1. 阅读只更新覆盖；自认熟悉独立显示，减少重复推荐；困难后重读即可继续。
2. 独立答案按目标分别更新，避免同页一个目标答对影响另一个目标的预测。只有页面全部当前已发布目标满足检查契约才显示“检查支持”。
3. 同目标同题族跨天重复也不再新增表现证据。原始事件保留，可查看或导出。
4. 未读、部分阅读、已读/自认熟悉、近期困难的阅读优先值分别为 1、0.75、0、1.2，再按所需时间和有界相关性排序；这些是导航偏好，不是预计学习增益。保留兼容字段 `expected_gain`，当前返回零。
5. 无题页面读完后不会因缺少题目反复进入阅读推荐。可选检查优先补充观察较少的目标，仍受时间、可用题目、范围和近期作答限制。

页面实验指数只汇总已作答目标，不代表页面全部内容的掌握。旧版阅读参数敏感性实验继续标记为 `bkt-reading-envelope-v2`，不得用新版模型名称覆盖历史结果。

## 4. 研究、对照与暴露出的瓶颈

研究依据、原始文献、数据划分与模型取舍见 [联合分析](题目分析.md) 和 [公开数据实验](实验结果与实施记录.md)。没有将公开数学答题数据的参数直接部署为企业阅读概率。

| 验证 | 观察结果 | 能支持的结论 |
|---|---|---|
| 两份公开答题数据留出对照 | 比较整体均值、技能均值、默认/拟合 BKT、历史逻辑回归；保留冷启动、校准与迁移上的负面结果 | 复杂模型不自动优于简单基线；企业场景需要本地数据校准 |
| 100 个固定种子的 8–10 节点图，对照独立穷举 | 新规划 100/100 达到给定效用的最优值，其中 50 个严格优于贪心 | 共同考虑前置与预算可以解决贪心的部分反例；不是学习收益证明 |
| 500 节点规模例 | 达到搜索上限，结果与贪心相同，上界很松 | 原型能有界运行，不能宣称近似全局最优 |
| 并发、统计、流程三个合成主题的实际材料生成 | 11 个候选，至少 5 个需要作者修订；来源不足例返回 0 个候选 | 结构可跨主题使用，但引文正确不保证语义正确；仍需来源复核 |
| 修订材料调用生产算法 | 三主题 11 个无题单元均可导入验证、预算推荐、阅读推进；旧来源版本被拒绝 | 原型不依赖十个演示目标，也不依赖题库才能闭环 |
| 页面回退反例 | 连续 365 天阅读不提高表现指数；跨目标不串用答案；重复题族不新增证据；困难后可继续 | 当前两个学习入口遵守同一证据边界 |

完整记录：[关联与路径](关联与路径验证记录.md)、[材料候选与跨主题验证](材料候选与跨主题验证记录.md)。材料复核者为本原型作者，不冒称独立评审。尚未获得真实学习者的耗时、应用表现或延迟保持对照；因此没有“比旧方案提高某百分比学习效率”的结论。

## 5. 隔离与个人数据权利

个人事件按知识库有效租户和登录主体隔离。接口不接收可任意指定的其他用户身份。查看学习内容复用知识库读权限，整理共享学习材料要求写权限。

导出与删除覆盖当前用户在全部知识库中的个人记录，包括共享库记录；不导出他人画像，也不删除共享学习材料。删除采用事务和删除世代校验，过期异步写入不能复活画像。停止采集后不使用个人关联。旧助手记忆有独立生命周期，删除学习画像后，必须有新的个人输入才可重新参与学习关联。

本次核对了真实画像入口与导出：导出文件包含 344 条事件、4 个知识库、1 个事件主体，其中含组件事件。删除通过隔离数据库中的生产仓储与服务测试验证，未删除真实用户数据。覆盖测试包括 `TestLearningRepositorySubjectScopedExportAndDelete`、`TestComponentCatalogueAndPersonalLifecycle`、`TestComponentMemoryHonorsResetWithoutDeletingAssistantMemory`、`TestDeleteProfileDataRollsBackOnMidTransactionFailure`、`TestExportDeleteCoverSharedTenantRows`。

## 6. 运行与逐项验收

按 [本地启动说明](../../../hls/WeKnora启动说明书.md) 使用现有开发环境：前端 5173、后端 18081；没有更换 Docker/WSL 部署方式。当前后端已重建，监听 PID 52796，健康检查为 `ok`。

真实查看 `langchain5.3prov3` 回退页面：41 节点、39 已接触、4 已阅读、0 检查支持；“提示词”本轮三步约 6 分钟，已读“少样本提示”未重复进入路径。阅读详情明确“尚无独立检查，不显示能力数值”。星图保留白绿布局、颜色图例与导航。测试阅读操作属于工程验收，不能当作学习者效果样本。

主样例 `weknoraq4` 使用十个报告学习单元；前一轮已实测目标与 5 分钟预算的前置路径、目标未覆盖提示和知识助手同步。本次统一只改变页面回退链，组件链的回归继续通过。两类入口没有共享或伪造个人检查证据。 新版后端上的助手也已重新实测：它正确回答阅读不等于掌握、当前十个目标为零已阅读和一个初步接触，第一步为「区分相关与先修」、约两分钟，与当前导航一致。
